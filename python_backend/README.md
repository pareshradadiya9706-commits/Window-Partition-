# Python Backend Calculation & Business Logic Engine

Package structure:
- `calculations/`: Window sizing, extrusion length deduction, cutting optimization, weight and glass area calculations.
- `models/`: Window profile, project, hardware, quotation and BOQ data structures.
- `services/`: Project management, estimation services, export services.
- `repositories/`: Catalog repositories and project storage interfaces.
- `tests/`: Verification unit test suite.
